# Footynomics

Price projections, cash cows and trade planning for AFL fantasy. Not affiliated with the AFL or the official AFL Fantasy or AFL SuperCoach competitions.

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Debug: view the site "as of" a round

Set `DEBUG_AS_OF_ROUND` to a round number (1-24) to see every page exactly
as it would have looked straight after that round:

```bash
DEBUG_AS_OF_ROUND=10 npm run dev
```

On Windows PowerShell: `$env:DEBUG_AS_OF_ROUND = "10"; npm run dev`.

- Round N is treated as the last completed round. Scores, prices, price
  changes and games after Round N are removed, players added later (such as
  mid-season draftees) do not exist, and later rounds are estimated by the
  scaled model from Round N's data and price total.
- The data is trimmed at build time (`.debug-data/round-N`, generated by
  `scripts/build-as-of-data.ts` from `next.config.ts`), so later rounds
  never reach the browser.
- The live-score feed is ignored, and an amber "Debug: viewing as of
  Round N" banner shows on every page.
- Unset (the default) changes nothing. It only turns on where the variable
  is explicitly set, so **do not set it on Vercel**. Restart `npm run dev`
  after changing it.

Development backtest: `npm run backtest:as-of -- 10` prints the Projector's
projections as of Round 10 beside the prices actually published later, with
the error per round (`--player <id>` for one player, `--mode` to change the
projection), and writes a CSV to `scripts/output/`.
