# SuperCoach Toolkit

## Vision

Build the fastest, easiest and most accurate AFL SuperCoach analysis platform.

The platform should provide powerful insights while remaining simple enough that a coach can get the answer they need in under 10 seconds.

---

# Project Principles

## 1. Speed First

- Fast page loads
- Fast calculations
- Minimal clicks

## 2. Mobile First

Most users will access the site from their phone.

Every page should work beautifully on mobile before desktop.

## 3. Accuracy Above Everything

Never invent data.

If data is unavailable, display:

"Data unavailable"

rather than guessing.

## 4. Build Once

Every calculation should exist in one place.

One projection engine should power:

- Price Projector
- Trade Planner
- Cash Cow Finder
- Future tools

## 5. Keep Costs Near Zero

Until the site gains traction:

- Free hosting
- Free database
- Manual weekly data updates if required
- No paid APIs unless justified

## 6. Respect the User

Ads should never interfere with usability.

The goal is to build a site people want to revisit every week.
